# AI use

This repository was drafted with Cursor’s coding agent from the project proposal.

The proposal says generative AI would be used for interface work, the gameplay loop, and tests, and that the database design and the database functions would be written by the group. The agent also wrote the schema, the seed data, the qualification checks, the applicant draw, and the end-of-day penalty, because the request was to build the whole game.

Review those parts before treating them as your own work, and disclose this file with the submission.
